1. **AWS launches frontier agents for security testing and cloud operations**
   - 概要：这篇 AWS Machine Learning Blog 宣布 AWS Security Agent 的按需渗透测试能力和 AWS DevOps Agent 正式可用，二者被归为 AWS 在 re:Invent 提到的 frontier agents。文章强调 frontier agents 与传统 AI 助手不同：它们可以独立完成多步骤目标、并发扩展大量任务，并在几小时或几天内持续运行而不需要持续人工监督。AWS Security Agent 旨在把渗透测试从周期性瓶颈变成按需能力，AWS DevOps Agent 则面向跨 AWS、多云和本地环境的事故响应、可靠性优化和 SRE 任务。
   - 为什么重要：这篇文章标志着 AWS 把 agentic AI 从“辅助生产力”推进到安全和云运维两个高风险核心流程。它的重要性在于，AWS 正试图让智能体承担原本依赖专家、排队和周期性执行的工作，例如渗透测试、根因分析和事故缓解，这会改变安全团队与运维团队的容量模型和 SLA。
   - 行动启发：安全或平台团队可以把这篇作为 frontier agent 评估入口：先选择低风险应用或非生产环境验证 Security Agent 的漏洞发现与报告质量，再用 DevOps Agent 对历史事故做回放分析，比较其根因定位、修复建议、执行边界和人工审批机制。
   - 来源：[AWS Machine Learning Blog](https://aws.amazon.com/blogs/machine-learning/aws-launches-frontier-agents-for-security-testing-and-cloud-operations/)；来源时间：2026-03-31（来源仅披露日期，北京时间）；阅读状态：read；阅读质量：high
