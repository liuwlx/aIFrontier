# Frontier News Digest

## Purpose

Use this skill to maintain `E:\workerspace\daily\frontier-data-hub`:

- Crawl configured AI/tech frontier sources.
- Normalize raw source items into local JSONL records.
- Start a real Article Reader Agent for each candidate article before final digest generation.
- Generate Chinese daily flash-news reports with article summary, why-it-matters, action hint, source link, and source time.
- Validate that every final item came from Article Reader Agent output, not title-only extraction.

This skill is source-time strict and reader-strict: never invent exact times, never use a title-only summary, and never let a local extractive script pretend to be the reader.

## Repository

Default repository:

```text
E:\workerspace\daily\frontier-data-hub
```

Core config files:

- `config/sources.yaml`
- `config/source_types.yaml`
- `config/topics.yaml`
- `config/filters.yaml`
- `config/digest.yaml`

## Required Workflow

1. Read `references/source-policy.md` when adding or reviewing sources.
2. Read `references/source-type-taxonomy.md` when assigning `source_type`.
3. Read `references/source-time-rules.md` before generating or editing daily reports.
4. Read `references/article-reader-rules.md` before generating a digest.
5. Read `references/article-reader-agent-prompt.md`, then start Article Reader Agent work for candidate articles.
6. Use `scripts/crawl_sources.py` and `scripts/normalize_items.py` only for crawling and normalization.
7. Write official reader output only to `data/agent-readings/YYYY/MM/YYYY-MM-DD.article-reader-agent.jsonl`.
8. Generate the daily report with `scripts/generate_daily.py`.
9. Validate the daily report with `scripts/validate_digest.py`.

## Article Reader Requirement

Before generating the final digest, every final candidate must be read by a real Article Reader Agent.

Preferred execution pattern:

```text
For each candidate item:
1. Locate its local raw JSON file under data/raw/YYYY/MM/DD.
2. Start one Article Reader Agent, or assign that exact file to an existing Article Reader Agent.
3. The agent reads the raw JSON `html` field and returns a structured Chinese JSON result.
4. If the article cannot be read, mark it blocked and exclude it from the final digest.
```

Official reader output path:

```text
data/agent-readings/YYYY/MM/YYYY-MM-DD.article-reader-agent.jsonl
```

Every final digest item must have:

- `reader_status = read`
- `reader_agent = Article Reader Agent`
- `summary_source = article_reader_agent`
- `summary_language = zh-CN`
- `reading_quality` in `high | medium`
- `article_summary`
- `why_it_matters`
- `action_hint`
- `reader_ran_at`
- `source_url`
- `time_display`
- `time_display_type`

Unread, blocked, low-quality, title-only, or local-script-only items must not enter the final digest.

## Required Daily Item Format

Every daily item must contain:

- Chinese article summary generated by Article Reader Agent.
- Why it matters.
- Action hint.
- Markdown source link.
- Source time or fallback crawl time.
- Reader status and reading quality.

Example:

```markdown
1. **AWS launches frontier agents for security testing and cloud operations**
   - 概要：AWS 宣布面向安全测试和云运维的 frontier agents 正式可用，重点覆盖按需渗透测试、事故根因分析和多步骤运维任务。
   - 为什么重要：这说明云厂商正在把 Agentic AI 从聊天助手推进到可承担生产级安全与运维工作流的自治系统。
   - 行动启发：如果团队使用 AWS 或多云环境，可先从只读分析、渗透测试补充和事故响应建议开始试点。
   - 来源：[AWS Machine Learning Blog](https://aws.amazon.com/blogs/machine-learning/...)；来源时间：2026-03-31（来源仅披露日期，北京时间）；阅读状态：read；阅读质量：high
```

## Hard Rules

- Do not fabricate publication times.
- If a source only exposes a date, do not add `00:00`.
- Convert recognizable foreign time zones to Beijing time before display.
- If timezone is unknown, keep date-only display or mark timezone unknown.
- Long-lived guides, whitepapers, and architecture docs prefer `updated_at`.
- News, product releases, and blogs prefer `published_at`.
- Every normalized item must include `fetched_at`, `time_display`, `time_display_type`, and `time_confidence`.
- Every digest item must come from Article Reader Agent output, not title-only summary.
- Local extractive scripts may be used only for development diagnostics; they must not be used as the official daily digest reader.
- A digest item without article summary, why-it-matters, action hint, source link, source time, or reader status is invalid.

## Output

Daily reports go to:

```text
reports/daily/YYYY/MM/YYYY-MM-DD.md
```

The report must include:

```markdown
## 概要说明

- 本日报条目必须经过 Article Reader Agent 阅读正文后生成，不直接把标题或列表页摘要当成正文概要。
- 每条快讯包含正文概要、为什么重要、行动启发、来源链接和来源时间。
- 若来源未披露发布时间，会展示本系统抓取时间；不会编造具体发布时间。

## 时间说明

- “来源时间”优先使用来源页面、RSS/API 或可核验元数据中明确披露的发布时间。
- 若来源只披露日期，则按来源日期展示，不补造具体时分。
- 若来源未披露时间，则展示本系统抓取时间。
- 若时间由 URL、列表页或搜索结果推断，会明确标注“推断”。
```
