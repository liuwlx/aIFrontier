# Source Type Taxonomy

Use the following common taxonomy for all providers:

| source_type | Label |
|---|---|
| `executive_insights` | 高管/行业洞察 |
| `data_leader_view` | 数据负责人视角 |
| `implementation_guides` | 落地指南 |
| `enterprise_genai_platform` | 企业 GenAI 平台 |
| `whitepapers` | 白皮书 |
| `production_architecture_check` | 生产级架构检查 |
| `ai_ml_practice_blog` | AI/ML 实战博客 |
| `product_releases` | 产品发布 |
| `annual_conference` | 年度大会 |
| `company_strategy` | 公司战略 |
| `genai_architecture` | GenAI 架构 |

## Classification Guidance

- Choose `implementation_guides` for how-to, migration, solution guidance, best practices, and step-by-step enterprise adoption material.
- Choose `enterprise_genai_platform` for platform product suites or platform operating models.
- Choose `production_architecture_check` for reliability, security, governance, cost, operational excellence, and production readiness checks.
- Choose `genai_architecture` for reference architectures and system design patterns.
- Choose `product_releases` for launch announcements.
- Choose `company_strategy` for shareholder letters, annual reports, major strategy narratives, and business model shifts.
